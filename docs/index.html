FabriFroge Launcher

A desktop launcher for the FabriFroge Minecraft: Java Edition modpack. It helps players install and update the pack, configure memory, and start the game.

Independent project · Private distribution

What it does

The launcher downloads the pack files and required NeoForge components, prepares the Java runtime when needed, and launches the configured game installation.

Account sign-in

Microsoft sign-in is used to verify a player's own Minecraft: Java Edition account and obtain the session needed to launch the game. The launcher opens the operating system's default browser for sign-in on Windows, macOS, and Linux, then returns to the launcher when authentication is complete.

Local account data

The launcher caches session information on the player's device so it can restore a signed-in session. The launcher does not ask users to type their Microsoft password into the launcher.

Get the launcher

Download the latest installer for Windows, macOS, or Linux from the FabriFroge download page.
